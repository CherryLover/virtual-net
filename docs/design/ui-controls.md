# 工作台控件规范

本轮只统一新增交互与现有工作台的外观，不引入另一套组件库，不改变网络图背景或配色范围。

## 复用入口

- 基础颜色、字号、间距、圆角与阴影：`apps/web/src/app/app.css`。主体 13px、辅助信息 12px、弹窗标题 16px，圆角统一 `--radius`（6px），间距沿用 8px 基准。
- 操作按钮使用 `.btn`，确认操作用 `.btn-primary`，危险操作用 `.btn-danger`；工具按钮使用 `ui/IconButton.tsx`（32px 方形、Lucide 图标、名称提示、键盘焦点）。不得为某个新增弹窗复制另一套关闭/刷新/缩放按钮。
- 输入框复用 `.field`、`.field-label`、`.field-input`；新增下拉框使用 `ui/Select.tsx`，保留原生选择、键盘、禁用语义，外层统一 32px 高度和箭头。长选项不撑宽面板。
- 新增弹窗共用 `ui/controls.css` 的 `.ui-dialog`、`.ui-dialog-heading`、`.ui-dialog-body`、`.ui-dialog-footer`；业务样式仅管理各自宽度、滚动区域和内容布局，不覆盖统一标题、边框、按钮和遮罩。
- 文件菜单与画布右键菜单共用菜单项规则：36px 行高、13px 字号、同一间距和选中底色；右键菜单只额外处理屏幕定位。
- 分组成员与设备选择共用 `.ui-device-choice`、`.ui-checkbox`，整行可点，选中底色跟随强调色，保留设备图标、名称和类型。计数用等宽数字。
- 所有新增控件须检查悬停、按下/选中、禁用、键盘焦点；禁用按钮不再显示可点击的悬停效果。成功/警告/错误保持原语义颜色。

## 本轮覆盖

分组名称与加入分组、成员勾选、多选对齐工具、画布右键菜单及常驻工具条；配色、设备选择、导入、导出和分享窗口。
