# CP4 网络区域与访问控制

> 状态：已完成，自动测试与整体页面验收通过（2026-09-07）。替代旧 CP4 特定边界方案。
> 依据：[ROADMAP](../../ROADMAP.md)、[设计方向](../design/network-model-and-ui.md)。

## 范围与决定

- 区域为可命名展示标签，设备位置、标签均不决定是否允许访问。
- 独立“访问控制”实体采用透明双口接入，实际经过哪台就检查哪台；不使用全局第一台规则。
- 主机与透明设备复用有序访问策略：首条匹配生效，默认允许；允许配置默认拒绝。
- 按方向、IP/网段、协议、端口与可见域名匹配。返回连接规则单独处理，不假定一次放行后所有流量都允许。
- 规则只能匹配实际可观察的信息；不以预设“协议风险等级”替代确定性判断。
- DNS 服务自己的记录应答与真实返回路径上的设备改写分别记录，只有实际查询服务或经过设备能影响结果。
- 改写后应继续验证实际返回地址：可失败，也可连接另一个有效服务，不把改写等同于断网。
- 目标列表可编辑，错误记录应指明设备、规则和字段。

## 已确定的行为

- 首条启用且匹配的规则生效；没有匹配时按默认动作，初始默认允许。拒绝终止模拟并定位，不额外模拟超时、TCP reset 或拒绝报文。
- 规则方向为入站、出站、转发或任意。单台设备依据当前连接看到的地址执行，NAT 前后的连接地址分别按实际位置处理；透明控制节点没有额外路由或独立地址。
- 已建立连接返回默认允许，可关闭。只有之前允许的相同协议、地址和端口组合的响应才按连接状态放行，其他来源或端口不享有该许可。
- IP 支持单地址与 CIDR；空值 / `*` 表示任意。域名不区分大小写，支持精确匹配和 `*.example.com`，后者不包含根域名。
- DNS 查询和明文 HTTP 请求可见域名。代理端解析的 HTTP / CONNECT / SOCKS5 请求携带目标域名；客户端先解析后传 IP 时，入口不携带原域名。入口的目标 IP 始终是代理地址，不是出口目标。
- 首批不实现 TLS/SNI 握手或加密 DNS，不仅凭端口 443 猜测域名可见。区域名称只作展示，不是规则条件。
- 服务器 DNS 记录是所查询服务自己的答案；没有本地记录时可配置上游并经实际路径查询。不扫描无关目标库推测另一个“原答案”。实际路径发生改写时，记录服务已有答案、最终地址及依次改写的设备。
- 一个目标域名当前只有一个 IP，但多个域名可以共用 IP。目标标识、域名需唯一；DNS 服务记录只允许完整域名，不支持通配符。

## 兼容与范围

新程序可读旧拓扑：缺少策略时保留原有行为，缺少区域时不增加标签。旧程序读取新设备或新字段不作保证。独立节点采用透明双口；主机和现有路由设备复用访问策略，不另做所有形态的路由型安全设备。CP6 / CP7 不在本轮实施范围。

## 不做

不做真实网络请求、概率性协议识别、动态路由、多地址 DNS 缓存或加密 DNS 全协议实现。模拟规则不是现实可达性的承诺。

## 步骤

1. 设备与服务模型、默认值、导入兼容和字段校验。
2. 逐路径访问策略、返回连接和 DNS 处理，每种失败先有引擎测试。
3. 通用节点、配置表单、区域标签、目标编辑和 DNS 查询入口。
4. 逐跳显示规则依据、DNS 原始与实际答案，诊断定位。
5. 旧图与旧模拟回归，再实际操作新页面场景。

## 验收

对应 R-20260907-01 至 04，并补以下真实场景。

- 电脑、网关、访问控制、互联网组成网络，默认通过；新增目标拒绝规则后失败定位正确；关闭规则恢复。
- 串联两台控制设备，两者均独立生效；不在路径的第三台不改变结果。
- 一条允许例外位于拒绝规则之前时按顺序生效；默认拒绝和返回连接有独立测试。
- DNS 查询直接返回与被改写分别展示来源；改写到有效目标仍能建立连接。
- 移动节点和修改区域不改变既有验证；改策略后验证过期。
- 模拟、导入、页面填写错误与旧场景回归全部验证后再打勾。
