# 已有设备查找与定位

## 范围（2026-09-10）

- 顶部放大镜“查找画布设备”用于查找图中已有设备，与左侧可添加设备库的搜索区分。
- 按设备名、设备地址、当前分配的接口地址和所属组名筛选。互联网节点支持按其外部目标地址查找，不搜索账号、密码或任意配置内容。
- 展示设备类型图标、名称、地址和所属组；无输入时列出全部设备，空图和无匹配有对应状态。
- 点击结果或输入后按 Enter 定位首个结果；无匹配时 Enter 不改变选择。Escape 和关闭按钮取消且保持原选择。
- 桌面定位选中设备、打开侧栏，并在布局稳定后将该设备移入视野；手机定位后收起覆盖画布的面板，避免结果被遮挡。定位只改变选择和视口，不新增撤销记录。
- 隐私模式下先脱敏再匹配，展示及提示均不泄露原始 IP；按原始地址搜索不能命中，按代称可查。切换模式时清空输入，真实网络配置不改动。
- 弹窗具有稳定高度、结果内部滚动和小屏约束，不随结果数量跳动，不拦截浏览器默认查找快捷键。
