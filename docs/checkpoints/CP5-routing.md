# CP5 第三批：网站访问分流

> 状态：已完成。对应 ROADMAP 的设备级分流，完整 CP5 仍未完成。

## 范围与约定

- 电脑、服务器、代理作为访问发起方时，可以保存网站访问规则。
- 启用后从上到下匹配第一条启用的规则；未命中直接连接。规则可按域名（含 `*.` 子域名）、直接输入的 IP / CIDR、目标端口匹配。
- 在解析之前选择路径；IP 规则只匹配直接输入的 IP，不提前解析域名，也不拿代理解析结果重新选路。
- 自动分流时目标端口缺省为 443，规则不能改变它；显式 HTTP 代理保留旧接口缺省 80 的行为，页面以用户填写的端口为准。
- 每条规则保存名称、启停、匹配类型、目标、可选端口和连接方式；代理连接包含协议、解析位置及模拟认证。模拟凭据随拓扑保存，不应用真实密码。
- 单次网站验证默认遵循设备规则，也可显式直连或选代理，覆盖规则。旧文件无规则时仍直连。
- 结果显示命中规则与选择方式；代理不存在、关闭、认证失败等沿用现有失败结果，绝不回退直连。
- 仅作用于发起的网站访问，不自动影响其 DNS 子步骤、独立 DNS 查询、ping、路由跟踪或代理出口；不实现透明网关分流、多级代理、任意 UDP 和隧道。
