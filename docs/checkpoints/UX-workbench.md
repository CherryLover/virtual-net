# UX 工作台与连线编辑

> 状态：已完成，页面、实际文件导入与自动测试通过（2026-09-07）。用户已授权实现并由开发侧决定小交互。
> 依据：[设计方向](../design/network-model-and-ui.md)。保留已有主画布与全部模拟能力。

## 本轮设计决定

- 工作台沿用浅色中性背景与中文字体，青绿用于主要操作，蓝色保留路径语义，红黄表示错误与警告。紧凑分区而非装饰卡片。
- 顶栏文件操作与编辑操作分组并固定在左侧，常用命令采用带提示的标准图标；名称移到右侧“已保存”之前，桌面上限 168px，手机上限 112px。“选择起点验证”保留为次要图标入口，不代表全网扫描。
- 步骤序号移到节点上方，避开端口标签，独立显示层高于选中节点；按节点宽度换行。播放期间适配画布增加留白，播放条与缩放控件错开。
- 设备库统一鼠标与触摸指针拖放，带阈值、预览和取消处理；松手只新增一次，保留点击/键盘添加。播放条统一图标，支持左右/Home/End 键盘操作。
- 左栏可搜索、分组和收起；新服务真正实现后才出现可添加的实体。
- 右栏按配置、端口、验证组织；名称与设备状态保持可见，错误能跨分组定位。
- 表单延续失焦校验提交；无效内容不写入网络，切换节点不带入旧草稿。
- 普通交换机默认上下分配端口，支持修改显示侧；只是显示位置变化，不增加或替换逻辑端口。
- 连线为三次贝塞尔曲线；选中后显示两个可拖控制柄，偏移相对端点保存，恢复自动入口使用图标。
- 拖动中预览，松手保存，一次拖动一次撤销；曲线和端口展示变化不使验证过期。
- 线形、标签、高亮与路径动画共用实际曲线；旧图无展示字段时自动生成。
- 桌面完整编辑；窄屏折叠侧栏，手机同一时刻只占用一个侧面板，画布仍可操作。
