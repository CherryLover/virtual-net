# 导入前分步检查

范围：ROADMAP 第 12 节的自由工作台完整网络图替换；学习备份单独识别并拒绝混用，不实现学习模块。

## 验收

- 文件、内容、节点、关联、确认五步保留结果，失败后的依赖步骤不冒充通过。
- 本地读取；不根据扩展名误拒有效 JSON；空文件、不可读、版本、结构、身份、引用及资源上限有具体说明。
- 上限统一为 5 MiB、200 台设备、500 条连线、每设备 64 个端口；超限完整拒绝，不截断。
- 地址等可编辑配置问题保留原值并提醒；结构损坏阻止；复用当前整体检查，不要求全网连通。
- 分组与配色保留且校验引用；模拟密码不进入问题说明。
- 取消和重选使旧读取失效，同文件可重试；检查不改画布。
- 确认替换前检查最新图，变化时再次确认；先持久备份最新原图，失败不替换；整次替换进一次撤销。
- 保存失败显示实际失败状态，不声称已保存；备份提供下载恢复入口。
- 小屏滚动可读、操作区固定可达，键盘焦点约束、Escape 取消、按钮有名称。

## 验证记录

- 引擎解析与代理路由 4 个文件、29 项测试通过，覆盖分组/配色往返、无效引用、空身份和可编辑服务配置。
- 网页检查、提交保护与对话框共 31 项测试通过，包含密码隐藏、无效代理引用、重选竞态、原图变化与备份失败；数据库备份 5 项测试通过。窗口卸载期间备份不得触发替换的测试也已通过。
- 200 台设备的上限输入完整检查通过，耗时低于 5 秒门槛；超限拒绝，不截断。
- 本范围格式检查、网页类型检查通过。
- 合并页面已验证桌面与 390×844 小屏真实 JSON 导入往返、配色/分组保留和坏文件阻止。
- 导入后若自动保存失败，沿用现有“保存失败”提示及重试机制，画布保留可导出的未保存修改；原图备份单独保存，不受自动保存覆盖。
