# IP 隐私显示

## 范围（2026-09-09）

- 分享按钮旁的眼睛开关统一隐藏/显示 IPv4 地址；覆盖公网、内网地址及名称、区域、端口和提示中嵌入的地址。
- 同一个地址在当前页面生命周期中使用相同的“地址 N”代称。隐藏开关仅控制当前页面显示，不写入项目，不改变验证、地址分配、保存和撤销记录；刷新页面恢复默认显示。
- 隐藏期间不渲染右侧配置和包头详情，禁用配置面板入口、发起新验证和导入，避免编辑区域泄露地址。已有演示仍可播放，失败原因中的地址使用相同代称；关闭隐私后恢复配置区域。
- 设备选择弹窗仍可用；成组、拆组、平移及图片分享不受影响。
- 图片采集使用已替换的画面，PNG、SVG、PDF 与分享图片共用同一采集入口。真实地址不会放在名称、提示或隐藏字段中供图片恢复。
- 原始 JSON 项目仍保留真实 IP；隐藏状态下导出项目必须再次确认。此功能不是项目文件脱敏，也不是域名、凭据等任意敏感文字的全面保护。

## 验证

- `privacy/display.test.ts`：公网/内网/URL/CIDR 地址、同地址一致、无效地址、原始状态不变。
- `canvas/useSpacePan.test.ts`：按下/松开、窗口失焦、拖动中不切换、先松开空格、表单与弹窗保护。
- `scripts/shortcuts-privacy-smoke.mjs`：真实 Chrome 验证 Mac/Windows 成组快捷键及撤销重做、空格平移和选中项保留、恢复框选、播放焦点、隐藏后的页面文字/输入值/提示、SVG 地址检查、PNG 真实生成下载、原始文件警告、390/320px 布局。
- `scripts/selection-smoke.mjs`：原有框选、右键、按钮成组、拆组、平移和小屏流程回归。
- 全量测试 432 项通过（224 引擎、208 网页），包含类型检查的构建通过。截图与导出证据：`/tmp/virtual-net-shortcuts-privacy/`。
