# UX 整体强调色

> 状态：整体强调色版本已完成本地统一验收。依据 ROADMAP 第 9 节；不启动学习模块、协议扩展或部署。

## 当前决定

### 配色选材修订

- 预设改为两组共六套：马卡龙（薄荷、晴空、樱花），柔雾（鸢尾、鼠尾草、陶土）。使用 [Radix Colors 3.0](https://www.radix-ui.com/colors) 的 mint、sky、pink、iris、sage、bronze sRGB 色阶，数值已核对对应发布包；风格分组是本项目命名，不代表官方马卡龙或莫兰迪标准。
- 不再用一个深色同时承担所有用途：浅色用于主按钮和选中底色，同色系深色用于图标、描边及文字，白灰工作区不变。所有预设图标对白色、按钮文字对常态及悬停底色均验证至少 4.5:1。
- 保存格式仍只保存强调色，通过对应预设恢复整套搭配；旧自定义强调色继续可用。新图默认薄荷，不覆盖已保存的配色。浏览器验证脚本：`scripts/palette-smoke.mjs`。
- 本次验收通过：416 项测试（224 引擎、192 网页）、lint 269 文件、包含类型检查的构建通过；保留原有单包体积提示。两个浏览器脚本实际通过全部六套切换、白灰底色、取消/自定义、保存刷新、桌面/手机弹窗、文件往返及分享 PNG 下载。截图与图片在 `/tmp/virtual-net-palettes/`。复用 5180 唯一开发进程。

1. 配色仅设置一个整体强调色，应用到当前工作台各区域的图标、选中态及交互重点。提供色块预设、自选颜色与恢复默认。
2. 页面、画布和节点保持固定白灰底色，不提供深色模式、背景色、设备填充色或类型、单设备、单连线覆盖入口。强调色不把节点或画布大面积染色。
3. 弹窗内修改草稿，确认后一次写入、一次撤销；取消、关闭和 Escape 不改变原配色。恢复默认也在确认后生效。
4. 强调色属于当前网络图，随保存、导入导出、恢复、撤销和重做保留；打开另一张图采用该图的强调色。它虽覆盖整个工作台外观，但不作为独立的浏览器页面主题保存。
5. 旧文件没有强调色时使用默认强调色。旧背景、设备填充及其他覆盖字段继续允许解析，但不参与渲染，不会把新界面恢复成旧的深色或彩色填充方案。
6. 成功、失败、警告等语义状态保持稳定，并保留文字或图标；强调色不可取代故障提示。显示变化不改变网络模拟或作废已有验证。

## 验收

- UX-C01：预设、自选和恢复默认正确；改变的是整个工作台的强调色，画布与节点仍为固定白灰底色。
- UX-C02：取消、关闭和 Escape 不改变内容；应用仅产生一次撤销，重做与刷新一致；真实文件往返保留强调色。
- UX-C03：不同强调色下文本、选中态和操作入口仍清晰；错误、成功、警告不只靠颜色区分。
- UX-C04：界面不再出现深色、背景色、节点填充色和逐项覆盖选项；旧文件的此类字段可读取但不影响渲染。
- UX-C05：桌面与 390×844 下弹窗可滚动、键盘可操作、无横向溢出；全局快捷键不能越过弹窗误改画布。
- UX-C06：完整测试、类型检查、代码检查、构建及实际浏览器操作均通过；本轮结果见下方记录。
