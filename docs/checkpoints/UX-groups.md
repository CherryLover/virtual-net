# 复制与持久分组

## 直接选择与右键操作（2026-09-08）

- 空白处左键拖动默认框选设备，框与节点相交即选中；Shift、Command 点选支持追加及再次点选取消。Windows/Linux 同时配置 Control 多选；macOS 的 Control-click 保留右键语义。修复节点点击覆盖多选为单选的问题。
- 画布左上常驻框选/平移切换、已选数量、成组及拆组按钮，中键也可平移；不必打开文件菜单或右侧栏才能成组。原手机勾选入口保留。
- 设备、多选区域、组名及组边框支持右键菜单：成组、拆分成组、复制。右键已选成员保留多选；右键未选设备切换到该设备。拆分成组解除所选设备涉及的组，不删除设备或连线；多个组一次拆分只产生一次撤销。
- 菜单限制在窗口内，支持方向键、Escape 和点外部关闭；编辑命令不能越过菜单触发画布快捷键。
- `scripts/selection-smoke.mjs` 已在 Chrome 实测 Shift/Command 增减选择、右键成组和拆组、撤销重做、无修饰键框选、画布成组按钮、平移切换、右下角菜单及手机工具栏；截图 `/tmp/virtual-net-selection/`。
- 本轮完整测试 419 项通过（224 引擎、195 网页），新增 3 项成组/批量拆组/空选择菜单测试。构建与代码检查通过；唯一开发地址仍为 http://127.0.0.1:5180/ 。

## 范围与约定

- 单选复制只复制设备；多选复制携带内部连线，外部连线不复制。
- 新设备、端口、MAC、服务、访问规则、分流规则及互联网目标拥有新身份。被同时复制的代理引用映射到副本；未复制的代理引用保留。
- 静态地址、网关、路由等配置不改写，复制后明确提醒检查地址冲突；自动地址由现有运行机制重新分配。
- 完整选中的组复制为新组；部分选中成员复制后不归组。
- 一个设备最多属于一个组，不嵌套。建立组至少选两台；移除成员后允许只剩一台，空组自动清除。
- 组边界随成员自动伸缩；拖动边框联动成员，点击成员仍单独编辑。
- 组面板可改名、勾选增删成员、解组；解组和删除组框不删除设备。
- 手动曲线控制点相对端点保存，组内连线整体平移，跨组连线随移动端点延展。
- 复制、成组、成员修改、改名、解组和整组移动各为一次撤销操作。分组进入保存、导入导出与恢复。

## 手机设备选择

- 文件菜单提供“选择设备”入口，通过勾选建立多选，不依赖 Shift 或 Meta 键。
- 窗口继承现有单选、多选或分组成员，支持全选、清空选择；确认后打开操作面板，可继续成组、复制或对齐。
- 取消和 Escape 不修改原选择；没有设备或未选设备时禁用确认；长名称换行，设备列表在小屏内滚动。
- 选择动作不修改网络图，也不增加撤销步骤。
